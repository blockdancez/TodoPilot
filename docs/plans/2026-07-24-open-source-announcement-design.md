# TodoPilot Free 开源公告设计

## 目标

面向小红书和 X 宣布 TodoPilot Free 已开源，引导读者在 GitHub 搜索
`blockdancez/TodoPilot`，并邀请 Star、Issue 与 Pull Request。

## 核心口径

- 开源范围是 TodoPilot Free，不把 Pro 私有服务描述为开源内容。
- 强调 macOS、本地 OCR、Today List、本地提醒和 Code Agent 完成监控。
- 强调 offline-first：截图、OCR 文本和任务数据留在用户的 Mac。
- 小红书使用中文开发者叙事和清晰功能清单。
- X 分别提供中文和英文短帖，直接陈述开源事实与仓库搜索方式。

## 避免的表达

- 不使用“全部代码开源”或“所有功能永久免费”等容易误解的表述。
- 不承诺尚未提供的签名、公证、自动更新或 App Store 分发。
- 不暗示 Codex、Claude Code 或 Cursor 官方背书。
